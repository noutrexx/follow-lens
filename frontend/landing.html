How it works

Three steps, then it is just history.

  1. 01

    Paste a session

    Copy the browser session value into config.json. No password is ever typed.

  2. 02

    Run a scan

    Followers and following are collected for each tracked account, with delays and a cooldown.

  3. 03

    Read the diff

    The dashboard compares the new snapshot with the last one and shows what moved.

FAQ

Does it ask for my Instagram password?+

No. It uses a browser session value you copy yourself. That value is sensitive, so it stays on your machine.

Can Instagram limit the account?+

Any automation carries risk. FollowLens spaces its requests and enforces a cooldown, but scans should stay conservative.

Where is the data stored?+

In the project's local data/ folder. Nothing is uploaded.

Can it monitor private accounts?+

Only accounts your own session can already see.
